Around Christmas time I presented [my first impressions](/2011/12/22/first-impressions-of-doing-bayesian-data-analysis/) of Kruschke’s [Doing Bayesian Data Analysis](https://www.librarything.com/work/10737618). This is a very nice book but one of its drawbacks was that part of the code used BUGS, which left mac users like me stuck.

Kruschke has now made [JAGS code available](http://doingbayesiandataanalysis.blogspot.com/2012/01/now-in-jags-now-in-jags.html) so I am happy clappy and looking forward to test this New Year present. In addition, there are other updates available for the programs included in the book.
