I installed the latest version (0.12) of [IPython](http://ipython.org/) from source in my mac, but forgot that I had a previous version (0.10) installed using easy\_install. When trying to run ipython I kept getting the error: `No module named terminal.ipapp`.

Fixing it. I ran `easy_install -m ipython` in Terminal, so Python doesn’t continue looking for the old package, [as explained here](http://packages.python.org/distribute/easy_install.html#uninstalling-packages). Then I was able to navigate to /Library/Python/2.6/site-packages and then use `rm -r ipython-0.10.1-py2.6.egg`. Now everything works fine.
